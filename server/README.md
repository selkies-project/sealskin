# SealSkin server

The API server, Caddy proxy and embedded web UI behind
[SealSkin](https://github.com/selkies-project/sealskin): self-hosted browser
isolation and remote application streaming.

This package is normally run through the
[linuxserver/sealskin](https://github.com/linuxserver/docker-sealskin)
container. The full documentation, including running from source and
packaging the wheel, is at
<https://selkies-project.github.io/sealskin/>.
