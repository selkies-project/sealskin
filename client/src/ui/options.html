    App Laboratory

    The App Laboratory builds a meta-app: a variant of an installed application with its own name, icon, autostart script, and a home directory that is already set up. You set the application up once in a customization session, and every user's first launch starts from a copy of that home directory.

    1. Describe the appPick the application to build on, and give the meta-app a name, an icon, and the users who may launch it.
    2. Customize it in a live sessionA customization session opens with the template home directory writable. Install extensions, sign in, arrange it as users should find it.
    3. Close the session to save the templateClosing the session from this page keeps the home directory as the template.

    Customization session open

    Everything changed in this session's home directory becomes the template. The session stays open until you close it here; it is not listed among your sessions.
