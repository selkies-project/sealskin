# SealSkin 0.4.2

Maintenance release.

## Changes

* **PRoot Apps catalogs from a private remote.** When
  `SEALSKIN_PROOT_APPS_REMOTE` names a private proot-apps repository, its
  apps keep their short names in a catalog. A session on a catalog now gets
  `PA_DEFAULT_REPO`, the registry of that remote, so `proot-apps install
  <app>` and the app's desktop entries resolve to the private registry
  rather than `ghcr.io/linuxserver/proot-apps`. Apps of any other remote are
  still installed by their full image name.
* Dependency updates for the server and the client.
