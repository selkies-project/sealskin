# SealSkin 0.4.1

Maintenance release.

## Changes

* **Collaboration rooms on LinuxServer.io images.** A room's viewers reach
  the container on the session's own login again, not a view-only login of
  their own. The view-only login broke collaboration in LinuxServer.io
  images, and it held nothing back: every collaboration session already caps
  each participant through its Selkies token.
* **Kubernetes pull secrets.** The server reads a session template's pull
  secrets on the first call, however recently the host booted.
