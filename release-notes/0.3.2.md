# SealSkin 0.3.2

Maintenance release.

## Changes

* **FPS gaming mode.** Keyboard lock and pointer lock are now requested at
  the top level so gaming mode activates reliably. Resolution changes from
  collaborators are debounced.
* **Audio on first interaction.** All audio channels resume on the first
  page interaction, not just the Selkies stream, so microphones pass
  through on the first click.
