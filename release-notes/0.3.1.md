# SealSkin 0.3.1

Maintenance release.

## Changes

* **Hardening.** Fixes for findings from automated code security scanning.
* **Mobile settings icon.** The gear icon is no longer hidden on narrow
  screens such as phones.

## Breaking change

* **Password protected public file shares.** Existing password protected
  shares stop working. Regenerate any share that needs a password after
  upgrading.
